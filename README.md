# Rakin Ziyad — Developer Portfolio

A personal portfolio website built to showcase my background, technical skills, projects, and professional experience as an Information Technology student and aspiring Frontend Developer.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Framer Motion
- Lucide React

## Features

- Responsive design
- Interactive project showcase
- Smooth animations and transitions
- Professional experience timeline
- Skills and education section
- Contact information

## Getting Started

Clone this repository:

```bash
git clone https://github.com/rakinziyad30-bot/rakin-portfolio.git
```

Navigate to the project folder:

```bash
cd rakin-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
